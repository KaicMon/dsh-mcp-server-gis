# MCP 项目学习计划

## 学习目标

完成本计划后，应当能够：

1. 解释 MCP、JSON-RPC 和本项目各模块之间的关系。
2. 独立构建、运行和调试 MCP Server。
3. 看懂 STDIO/SSE 请求的完整处理链路。
4. 使用 MCP Client 发现并调用工具。
5. 独立开发、构建和加载一个 MCP 插件。
6. 理解 RAG-MCP 如何进行工具检索，并能调整其检索策略。
7. 找出当前实现的主要边界、风险和可改进点。

## 学习方法

每个阶段都按照“概念 → 源码入口 → 跟踪调用链 → 动手验证 → 回顾”的顺序进行。

- 总计划只保存稳定的学习路线和总体进度。
- 每天在 `每日记录/日期.md` 中记录实际学习内容。
- 学习时先记录事实、疑问和实验结果，不急于写成完整文章。
- 当天学习结束后，再根据要求把记录整理成结构化笔记。
- 涉及现有构建目录或用户改动时，不直接清理或覆盖。

## 建议节奏

不强制按自然日划分，按掌握程度推进：

| 学习单元 | 建议投入 | 重点 |
| --- | ---: | --- |
| 项目全景 | 1–2 小时 | 先建立地图，不钻细节 |
| 服务端与协议 | 3–5 小时 | 跟踪真实调用链 |
| Transport | 2–4 小时 | 生命周期和并发 |
| 插件系统 | 3–5 小时 | 必须动手写一个插件 |
| Client | 3–5 小时 | 进程通信和错误处理 |
| RAG-MCP | 4–6 小时 | 向量、缓存、检索策略 |
| 测试与改进 | 2–4 小时 | 用实验验证理解 |
