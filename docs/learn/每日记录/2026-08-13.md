## 今日概念

- EmbeddingCache 用 `list + unordered_map` 同时提供 LRU 顺序和平均 O(1) 查找。
- TTL 是从写入时间开始计算的固定 TTL，仅在访问时惰性清理，并非滑动过期。
- VectorIndex 以工具名为键保存工具元数据和向量；当前搜索为全量扫描、余弦计算、全量排序、阈值过滤和 Top-K 截断。
- 余弦相似度比较向量方向而非长度；维度不一致或零向量在当前实现中返回 0。
- 当前 CMake 没有注册 CTest 单元测试；现有验证主要依赖 Shell 冒烟测试、Python MCP SDK 客户端脚本和示例程序。
