## 今日概念

- `name` 是稳定调用标识，由 Server 用于定位 Plugin，也由 Plugin 用于定位内部 Tool。
- `description` 帮助人和大模型判断何时选择 Tool。
- `inputSchema` 描述参数契约，但当前 Server 不负责完整执行 JSON Schema 验证。
- Plugin 必须对外部参数执行运行时验证，不能依赖 Client 一定遵守 Schema。
- Plugin 返回 MCP Tool result；Server 再添加 JSON-RPC `jsonrpc`、`id` 和 `result` 外层。
- Tool 执行动作，Prompt 生成 LLM 消息模板，Resource 通过 URI 暴露可读取内容。

## 关键文件与调用链

- `mcp_server/plugins/calculator/Calculator.cpp`
- `mcp_server/src/main.cpp`
- `mcp_server/src/interface/PluginAPI.h`

```text
methods 元数据
  → tools/list
  → Client/LLM 选择 Tool
  → tools/call
  → Server 定位 Plugin
  → Plugin HandleRequest 按 name 分发
  → 验证并执行
  → content/isError
  → Server 包装 JSON-RPC Response
```
